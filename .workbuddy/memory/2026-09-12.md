# 2026-09-12 工作日志

## 工程分析：TraeCar 循迹小车
对 `D:\Stm32CubeProject\STM32C8T6\TraceCar\TraeCar` 工程做了完整代码审查。

### 工程概况
- MCU：STM32F103C8T6，72MHz（HSE 8MHz → PLL×9），CubeMX 生成 + HAL 库 + MDK-ARM。
- 功能：双轮差速循迹小车，灰度传感器循迹 + 编码器闭环 + 串级 PID + 终点停车。
- 外设：TIM1(10ms控制中断)、TIM2/TIM4(编码器)、TIM3(PWM)、USART1(VOFA调试)、USART2(灰度传感器)、ADC1(PA6)。

### 控制策略（串级 PID）
灰度加权质心偏差 pos_error(-3.5~+3.5) → 偏移环 PID(仅Kp) → 左右轮目标速度(BaseSpeed±steer) → 速度环 PID → PWM。终点停车用位置环减速曲线。

### 发现的问题（待修复）
1. vofa.c `VOFA_SendData` 的 snprintf size 参数错误：应为剩余空间 `sizeof - current_position`，现写死 100，有缓冲区溢出隐患。
2. gray.h 注释过时：注释写 USART3/PC10/PC11，实际是 USART2/PA2/PA3。
3. 编码器上下拉不一致：TIM2(右轮 PA0/PA1)用 PULLUP，TIM4(左轮 PB6/PB7)用 NOPULL。
4. motor.h 中文注释乱码（GBK 被误读）。
5. `Controller_Set_Target_Position` 只设置 A 轮 target，B 轮位置环不对称，停车可能偏斜。

### 关键宏定义（main.h）
- MaxDistance=10m、Purple_min=3333、Purple_max=3777（终点紫色区域）、End_Move=960*3。

## 对照示例代码（USART_Tracking，标准库版）
对照 `D:\BaiduNetdiskDownload\1.STM32-mini底盘小车\USART_Tracking\USART_Tracking`，评估 gray.c 能否实现相同功能。

### 结论
功能可实现（串口收帧 + 数字量/模拟量解析 + 配置帧发送均正确），但存在 3 处差异需注意：
1. **串口号**：示例用 USART3(PC10/PC11 部分重映射)，本工程用 USART2(PA2/PA3)——gray.h 注释仍写 USART3，已过时。
2. **帧解析方式**：示例数字量用固定偏移 `new_package[6+i*5]`，本工程用 `strchr` 逐 token；两者数字量解析一致（pos=6+i*5）。模拟量示例用 strtok 分隔，本工程用 strchr 冒号/逗号，均能解析 8 路。
3. **配置帧发送**：示例 `send_control_data(0,0,1)`（只收数字量），本工程 `Gray_SendConfig(1,0)`（只收模拟量）——本工程用模拟量加权巡线，示例用数字量查表巡线。

### 注意点
- 示例查表法巡线(`LineWalking`)对本工程无对应实现，本工程用模拟量质心加权法，思路不同但功能等价。
- gray.c 的模拟量解析用 `strchr` 从 `$A` 后开始，冒号/逗号边界处理正确，无溢出。
- 协议一致：`$`开头`#`结尾，波特率 115200 8N1。
